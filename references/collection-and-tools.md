# 采集与工具

## 路由

优先发现当前已连接且能力匹配的工具；平台采集读取bggg-data-amazon/reddit/x相应SKILL.md。浏览器接口随环境变化，不把某个API、绝对路径或旧网络错误当固定做法。

用户仅允许渲染页面时，用页面读取、滚动、可见筛选和链接，不执行默认Woot AJAX、Reddit JSON fetch。用户未限定方法时才按采集skill默认公开路径、速率和证据规则执行。没有合适工具就说明缺口，不能用虚构数据补齐。

Python标准库用于规范化、统计和校验；PDF/DOCX/表格/PPT任务读取当前相应技能和依赖加载工具。图表用真实统计；静态研究图可用标准绘图或PDF矢量，证据探索用HTML内嵌索引。绘图库不可用时可选其他已安装且能正确呈现数据的方案。

## 停止与重试

先验证一个目标再扩批。暂时连接或请求失败保守退避、有限重试，通常最多3次，平台更严格时从严；保留每次文件和错误。稳定禁用或返回同内容就记录，不循环改参数探测。验证码、权限/登录墙按限制停止，不能绕过。

停止理由：量达上限、无后续页、重复游标/无新ID、稳定限制、验证码、授权不足。达到目标量即停；采不到完整树或full要报告部分覆盖。保存请求模式与实际执行方法，不宣称同义。

## Amazon

- basic/full/max具体定义看当前平台skill；full仍不保证全量。
- 重点款full，其他款按目标决定；重点未指定可说明默认方案，不无声扩大无限采集。
- 总评分不是文字评论数；schema变化或0行先检查再判成功。
- 原始尝试独立留档，合并有效内容并去重，保留关联变体ASIN。
- 评论标注国家与配送地区不同；不为采集修改配送设置。
- 页面混入旧表带、其他设备时按内容排除、保留原因；不能据此指控操纵。

## Reddit

- 保存查询、排序、时间窗；精确短语等补充查询单列，不冒充原查询。
- 按主题适配和互动选择母帖，注明目的抽样；互动不代表需求普及率。
- 每母帖封顶按本次参数设置，不固定50或总150。原渲染可能一次加载超限，证据可保留但分析集遵守上限。
- 原生ID、母帖、层级和作者角色保留。商家创始人回复不计独立消费者；本体、配件、闲聊分开。
- 完整树和封顶有范围差异，披露未展开节点；未知为null，不把搜索引擎摘要替代完整评论。
- 英语不证明美区，三个月前不证明精确日期；没有评论级URL就标母帖级。

## X

只有任务涉及X才使用bggg-data-x。按当前skill和用户授权读公开渲染时间线，不导出Cookie、token、profile、内部接口或其他凭据。原文、日期、互动、来源独立记录。

## 文本与隐私

清洗前检查UI文字、flair、Vine提示、引用块、机翻和广告。脱敏公开副本不覆盖原始证据；公开包不附私人浏览器侧栏或账号信息。
